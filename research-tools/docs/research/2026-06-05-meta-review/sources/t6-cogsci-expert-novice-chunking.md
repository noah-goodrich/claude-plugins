## Key Findings

- Expert advantage is PATTERN RECOGNITION, not raw search/computation. Skilled chess players recall far
  larger meaningful chunks than novices — but the advantage collapses for RANDOM board positions.
- Therefore expertise = a large library of recognized, domain-specific patterns stored in long-term memory
  (chunking), letting experts represent a problem by deep structure rather than surface features.
- Parallels Chi, Feltovich & Glaser (1981): experts categorize physics problems by underlying principle;
  novices by surface features. Expertise is fundamentally a REPRESENTATION advantage.
- Design implication: a tool augmenting a novice can't fake an expert's pattern library, but it CAN supply
  deep-structure representations / re-framings that nudge novices toward expert-like problem encoding — and
  it should not assume more brute-force search substitutes for better representation.
