## Key Findings

- Functional fixedness = "a cognitive bias that limits a person to use an object only in the way it is
  traditionally used." It is the object-level cousin of design fixation.
- Duncker's candle problem: most people fail to see the tack-box itself as a candle platform because it is
  framed as a container — the prior FUNCTION blocks the novel use.
- Adamson (1952): presenting the box EMPTY (decoupled from its container role) made participants ~2x more
  likely to solve. Mechanism is precise and manipulable: how an element is FRAMED determines whether it is
  available for recombination.
- Design implication: an ideation tool should actively RE-FRAME / decompose objects and concepts away from
  their default function to widen the search space.
