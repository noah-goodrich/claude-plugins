# Research Tools

Systematic research methodology plugin for Claude Code. Provides a deterministic, repeatable
pipeline for conducting deep research — from framing the question through producing a defensible,
documented deliverable.

Built on established frameworks (CREDIBLE, CRAAP, SIFT, RADAR, PRISMA) but extends them into a
unified end-to-end pipeline that no single existing framework covers individually.

## Skills

| Skill | Trigger | Description |
|-------|---------|-------------|
| `deep-research` | `/deep-research` | Full research methodology pipeline: design, discovery, 10-dimension source evaluation, evidence classification, inclusion/exclusion decisions, synthesis, and documentation |

## Prior Art

This plugin synthesizes and extends six established source evaluation and research frameworks:

- **CREDIBLE** — 8-component source evaluation (most comprehensive single framework)
- **CRAAP** — Currency, Relevance, Authority, Accuracy, Purpose (widely taught)
- **SIFT** — Stop, Investigate, Find, Trace (process-oriented, web sources)
- **PRISMA** — Systematic review inclusion/exclusion pre-registration
- **RADAR** — Rationale, Authority, Date, Accuracy, Relevance (academic)
- **DeepTRACE** — AI citation audit, 8 reliability dimensions
